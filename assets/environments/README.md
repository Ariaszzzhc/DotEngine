# Environment assets

`studio_small_09_1k.hdr` is the unmodified 1K Radiance HDR panorama from
[Studio Small 09](https://polyhaven.com/a/studio_small_09), authored by Sergej
Majboroda and shared under [CC0](https://polyhaven.com/license).
[Original download](https://dl.polyhaven.org/file/ph-assets/HDRIs/hdr/1k/studio_small_09_1k.hdr).

Official byte size: 1,615,248. Official MD5: `d5d7eb9d26d341d6aa4d11c1a54fd97c`.
SHA256: `e7cfda5f4e98e623db12b8bfd0184e048488e4855d9c83e2751fb44a32e80c45`.

The engine loads this local resource offline. Runtime code contains no Poly Haven
API client. GPU acceptance verifies conversion/convolution/BRDF resources, scene sky/IBL
and isolated asset/material previews. The editor packages its own copy with this
credit so preview lighting does not depend on a demonstration project.
