# Prism Relay asset sources

Original geometry in meshes/ is authored for DotEngine.
It is stored as ordinary native mesh resources; Python is not needed to open or run the game.
The former crystal OBJ and material are removed with the collection-prototype props.
The former drone and round-feedback PCM are removed.

Downloaded texture files are unmodified 1K JPEGs from Poly Haven (CC0):

- Metal Plate, Rob Tuytel: https://polyhaven.com/a/metal_plate
- Concrete Floor Worn 001, photography Dimitrios Savva, processing Rico Cilliers:
  https://polyhaven.com/a/concrete_floor_worn_001
- Studio Small 09 HDRI, Sergej Majboroda: https://polyhaven.com/a/studio_small_09
- License: https://polyhaven.com/license

ARM files pack ambient occlusion in R, roughness in G and metallic in B.
Normal files use OpenGL +Y tangent-space convention. Color is sRGB; ARM and normals
are linear. Texture data is used in the actual PBR pipeline, not as baked lighting.
All inputs remain local and exports run offline.

## Surveyor maintenance armor and locomotion

Character geometry and FederalSoldierSkin textures are adapted from Irondust's
CC0 Sci-fi soldier:

- Source and license declaration: https://opengameart.org/content/sci-fi-soldier
- Original archive: https://opengameart.org/sites/default/files/Sci-fi%20Soldiers.zip
- License: CC0 1.0 Universal, recorded at models/Irondust-LICENSE.txt.
- Original archive SHA-256:
  4a91f4ae01117656c9a5a8fc71930f852b2c4d3e94f3f9a2c88109ad931e0db4
- Adapted models/surveyor.glb SHA-256:
  d57844c3205a3d00f9815f7dd1c2dded758c9fb9bff38ae7866b040c9bc373d5

The adaptation uses Body, Head1 and HandSimple, with no cannon/weapon geometry.
It retains the real 63-joint rig and all positive source influences (up to eight
per vertex), normalizes weights and corrects the rest pose for locomotion transfer.
Seven baked clips use the original animation donor below, with target leg-proportion
adjustments during authoring. This is baked animation data, not runtime IK or a
procedural skeleton. The source GLB retains editable geometry, weights, materials,
images and all clips; opening or running the project requires no authoring helper.
Blender 4.5.14 LTS was an external authoring tool, not an engine dependency.

The 2048px material inputs use sRGB base color/emission, linear tangent normals and
linear packed occlusion R / roughness G / metallic B. The upstream specular-glossiness
material is converted to metallic-roughness using the dielectric 0.04 workflow
conversion described by Microsoft's glTF SDK:
https://github.com/microsoft/glTF-SDK/blob/master/GLTFSDK/Inc/GLTFSDK/PBRUtils.h
Its gloss-map factor 0.85 and emission factor 1.3 are retained. This changes material
workflow; it is not a claim of pixel identity with the donor's original renderer.
Native meshes/skins/clips/materials/images in surveyor/ are generated by the ordinary
editor model importer. The saved authoring pose is sampled by native animation
preview and applied using ordinary document transform operations. Other entities
and linked environment placements are unchanged.

Animation donor:

- Quaternius, Universal Animation Library Standard:
  https://quaternius.com/packs/universalanimationlibrary.html
- Author's download page: https://quaternius.itch.io/universal-animation-library
- Pack license: CC0 1.0 Universal, retained at models/LICENSE.txt.
- Source file: Unreal-Godot/UAL1_Standard.glb, without root motion.
- Original archive SHA-256:
  cc73fc4e495b82958207316596317a3f40b9fa38065bde1027937452da537724
- Retained adapted models/locomotion-source.glb SHA-256:
  b0adf827bb729b2774ed1104f407720eeff9ba1aa684cdad081e8258f9a72915

That source keeps the real 65-joint mannequin and idle/walk/jog/sprint/jump-start/
airborne/landing tracks for further authoring. It is an animation donor, not a runtime
fallback. The runtime character is the new surveyor/ bundle; physics owns root motion.

## Industrial equipment and ventilation

Utility Box 02 and Modular Airduct Rectangular 01 are Poly Haven CC0 assets:

- https://polyhaven.com/a/utility_box_02
- https://polyhaven.com/a/modular_airduct_rectangular_01
- https://polyhaven.com/license

Original 1K glTF/bin/JPEG inputs remain in models/, alongside PolyHaven-LICENSE.txt.
PolyHavenSources.json records all thirteen download URLs, byte sizes and SHA-256
hashes. Downloads were checked against the publisher's byte sizes and MD5 values.
The editor's ordinary model importer produced utility-box/ and airducts/; source
pixels, including signed normal RGB, are preserved in lossless native PNG images.
The imported materials are authored to use the ARM image's red channel as baked
occlusion; the upstream glTF binds its green/blue channels but omits that AO slot.
Straight/support scene assets were extracted and edited through product operations,
then instantiated/grouped in the main scene. Cabinets use fitted box colliders;
duct runs use simple box proxies. No mesh-generation helper or external authoring script is
required to open, edit or export the project.

## Authored character action study

`actions/inspection.dotanimation` is original project motion authored and saved through
DotEditor's pose creation, key editing, dope-sheet range selection, clipboard, bulk
deletion and group retiming. It uses the existing Surveyor binding map; no external
animation clip was copied into this action. The character/source licenses above
remain unchanged. It keys the actual head and upper-arm joints, preserving the rest
of the authoring pose. The editable `scenes/character-action.dotscene` selects this
auto-playing action with the locomotion script removed; main remains the movement/
jump/checkpoint template. This is a timing/authoring example, not final cinematic art.

- `actions/inspection.dotanimation`: `97046f1fdf5492d1ca2e80bc7982d3ccdca4c8400935424fefa98295b9a82411`

The inspection peak was subsequently aligned through DotEditor's shared rational frame
grid and native group retime to frame 24 at 30fps (nominal 0.8 seconds; native float
0.800000011920929). In that alignment only the three head/upper-arm key times changed; values, tangents,
channels, bindings and the scene remain unchanged. Frame rate is an editor view
preference; the asset retains seconds and does not alter runtime simulation timing.

The next authoring pass explicitly converted only node eight's head rotation to
cubic and set its first key's outgoing raw quaternion Y derivative to native 0.15
per second through the editor's owned tangent transaction. Other head derivatives
are zero; its key times/poses and all other tracks remain unchanged. Candidate
curves, failed zero-scale publication/recovery, Undo/Redo, save/reopen, Play and a
relocated standalone export were exercised with the actual products. The mode and
derivative change is explicit, not an import/resample or external motion donor.


The saved main scene now appends this existing motion to the seven unchanged
locomotion slots and authors an Inspection masked override layer through the actual
editor Inspector. Only logical rotation channels 8/10/33 (head/left/right upper arm)
participate. The action resource itself is unchanged from the cubic authoring pass.
Layer controls/native fades are engine functionality; no new motion donor, baked
replacement, mesh generator or external art is introduced. Required empty layer
arrays were added to current imported/action scene player transports without a
legacy decoder. The original GLB, textures, meshes/skins and locomotion files remain
unchanged, with their existing licenses/hashes above.
